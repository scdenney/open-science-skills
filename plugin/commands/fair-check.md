# FAIR Check

Run the `replication-package` skill in **audit mode** with the FAIR block: audit the manuscript and any replication package against Findable, Accessible, Interoperable, and Reusable. Cover data, code, materials, prompts, preregistrations, repository links, persistent identifiers, metadata, licenses, access restrictions, and availability statements, and prompt the author for anything missing.

Skip the scaffold path even when the target directory is empty. Report the package block only if a package path is supplied.
